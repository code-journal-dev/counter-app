# counter-app

A simple counter application built using HTML, CSS, and JavaScript.  
This project helps in understanding basic DOM manipulation and event handling.

---

## 📌 Features
- Increase counter value
- Decrease counter value
- Reset counter to zero
- Color changes based on value:
  - Green → Positive number
  - Red → Negative number
  - Blue → Zero

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

---

## 📚 What I Learned
- DOM manipulation using JavaScript
- Event listeners (click events)
- Updating UI dynamically
- Basic styling with CSS Flexbox
- Handling state using variables
